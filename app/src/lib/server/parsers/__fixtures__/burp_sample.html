 Severity:   High

Host:   https://app.example.com
Path:   /api/v1

Issue detail

The application implements a CORS policy for this request that allows access from any domain.

Issue background

Cross-origin resource sharing (CORS) is a browser mechanism.

Issue remediation

Use a whitelist of trusted domains instead of a wildcard origin.
